# Agent Mention、图片工具记录与设置页交互收口

## 分类与状态

- 分类：功能优化 / 用户体验优化
- 状态：进行中（补充修复窄宽度联网、MCP 图标 Tooltip；Git 私有远端检查待实机）

## 背景与目标

工作区已有文件、目录和 Skill Mention，以及对话图片识别、图片写入笔记和 Skill Git 更新能力，但部分交互的反馈与真实行为不一致。本需求让文章预览能直接跳到富文本编辑器，Skill 以说明 Tooltip 呈现，文件树可拖入 Agent 输入框生成结构化 Mention，图片识别在工具链中明确呈现已查看的图片；同时统一设置页分段 Tab 的尺寸，并只在 Git 来源确有新版本时展示 Skill 更新入口。

## 范围与非目标

- 范围：文件与目录 Mention 预览及内容预取、输入与消息气泡的 Mention 悬停反馈、文件树到 Agent 输入框的拖放、图片识别执行记录、Agent 工具链实时反馈、提问卡片与已回答历史的工具链视觉统一、设置页自实现 Tab、Skill Git 更新状态。
- 非目标：不改变 Agent 图片识别模型协议、图片对象存储写入策略、Skill 安装来源和权限边界；不恢复已关闭的最终资料/文件回执卡。

## 影响分析

| 维度 | 已确认内容 |
|---|---|
| 写入入口 | 文件树拖放只写入浏览器端 Agent 草稿的结构化 Mention；图片工具记录由后台 Worker 的持久化 run event 写入；Skill 更新检查只读取 Git 远端状态，不修改 Skill 内容。 |
| 读取方与状态传播 | Agent 输入框、用户消息气泡和预览弹窗共用 Mention 元数据；文件 Mention 在悬停时预取正文、弹窗复用内存缓存；刷新后草稿仍由 IndexedDB 还原；会话恢复从 run events 按用户消息 ID 重建图片查看记录，点击工具步骤只传递该步骤自己的图片集合；MCP 可用性由输入区读取启用服务数，无服务时清除本地 `auto` 偏好并显示配置引导。设置 Skill 列表读取 `can_update`。 |
| 边界 | 文件拖放仅接受工作区文件与目录、禁止浏览器文件上传语义；受控图片 URL 必须携带会话归属；远端 Git 检查失败时保守隐藏更新按钮且不影响启停与扫描。Web、Electron 共用前端与 API。 |
| 已检查但不受影响 | 图片写入笔记仍复用既有预览、确认和对象存储链路；MCP、检索和最终资料回执开关不变。 |

## 本次完成记录

- 本地保存并真实测试 `claude-sonnet-4-6`（Anthropic 协议）与 `tongyi-embedding-vision-flash-2026-03-06`（多模态 768 维）配置；实际工作区仅保留 3 篇展示笔记。
- 真实 Agent 任务观察到受理后 5 秒内的运行计时、`search_knowledge → read_file → preview_file_revision` 的逐条到达；完成态一般折叠，但包含图片查看记录时保持展开，最终消息的文件全文修订卡可打开“查看详情”。
- 提问卡片和已回答历史不再使用抽屉式独立卡片：统一为工具链的单列摘要、主色图标、展开详情与操作区；回答选择、逐题复核、键盘导航、暂存和后台续跑不变。
- 个性化页在窄屏验证图片上传位置已显示“本地 / 腾讯 COS / 阿里 OSS / R2”，无障碍名称仍为完整服务名称。
- AI 输入工具栏按面板宽度分三档：680px 以下先将自动/手动缩为 icon，560px 以下再将联网和 MCP 缩为 icon，390px 以下才让联网和 MCP 作为一组换到下一行；模型和发送固定右下。模型名、联网和 MCP 均保留不越界 Tooltip，390px 以下继续隐藏次要图片添加入口，收敛过渡遵循减少动态效果偏好。
- 无可用 MCP 服务时，MCP 不允许进入自动模式；点击入口只显示“需要配置 MCP 服务”弹窗，用户可关闭或直接前往 MCP 设置。服务数量异步检查完成后才清除旧 `auto` 偏好，避免初始加载阶段误关闭可用服务。
- 图片工具链以用户消息 ID 作为步骤标识；预览层只接收用户点击的工具步骤携带的图片数组。两条消息、两组图片的回归已确认图片 ID 不会交叉。
- 设置弹窗在 700px 以下以标题栏菜单按钮打开左侧抽屉导航，点击抽屉空白遮罩或选择任一菜单项后关闭抽屉；外层弹窗关闭边界保持不变。
- 设置弹窗标题栏和各内容区顶部均不重复显示当前设置功能名，当前功能仅由导航选中态表达；窄屏标题栏仅保留菜单 icon 与关闭按钮。
