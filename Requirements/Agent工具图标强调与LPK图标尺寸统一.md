# Agent 工具图标强调与 LPK 图标尺寸统一

## 需求范围

工具链的所有工具调用图标统一使用 Notus 主色。工具行折叠时只显示图标、工具名称和展开箭头；调用参数和结果仅在展开详情中显示。根目录 `logo.png` 是 LPK 打包图标，尺寸固定为 `512×512`；Web 的 `notus/public/logo.png` 保持原尺寸。

## 影响分析

| 范围 | 处理与结论 |
| --- | --- |
| 界面读取方 | `ToolChain` 与提问卡片复用 `ToolTraceIcon`；通过工具图标容器统一继承主色，不改工具类型、状态机或详情数据。 |
| 打包资源 | LPK 打包链路使用仓库根目录 `logo.png`；仅缩放该文件，不改 Web favicon、Electron `.icns/.ico` 或打包脚本。 |
| 已检查且不受影响 | 工具参数、结果、脱敏、工具权限、SSE、历史恢复、确认卡和模型选择均不变。 |

## 行为验收

| 用户入口 | 预期行为 |
| --- | --- |
| 工具记录折叠行 | 每类工具图标均为 Notus 主色；只展示完整工具名称与展开箭头。 |
| 工具记录展开详情 | 显示既有工具名、调用参数、结果和恢复操作，不在折叠行重复显示摘要。 |
| LPK 打包 | 根目录 `logo.png` 的 PNG 宽高均为 `512`；不重新打包 `.lpk`。 |
