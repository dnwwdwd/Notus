# LLM配置支持手动修改提供商

## 类型

功能优化

## 背景

当前 LLM 新增/编辑弹窗中的“提供商”字段是只读自动识别，用户无法在第三方兼容网关、代理地址或模型命名不规范时手动纠正提供商归属。这会影响模型分组展示、配置管理和部分调用语义判断。

## 需求

1. LLM 新增/编辑弹窗中的“提供商”必须支持用户手动修改，不能保持只读。
2. 提供商仍可基于 Base URL 和模型名自动猜测，但自动识别只能作为默认值，不能阻止用户覆盖。
3. 保存后的 provider 必须直接写入配置，并继续用于设置页列表展示以及知识库页、创作页的模型分组标签。

## 实现结果

1. 设置页与引导页共用的 LLM 配置弹窗已将“提供商”从只读字段改为可编辑 input，默认值来自自动识别结果。
2. 新增配置时仍会按 Base URL 和模型名自动推断默认 provider；用户修改后，保存时优先使用手动选择值。
3. 弹窗提示文案已同步调整为“默认自动识别，但允许手动修改”，避免继续误导为只读规则。

## 验收

- 新增或编辑 LLM 配置时，可以直接手动编辑 provider 文本。
- 不修改时，provider 仍会沿用自动识别默认值。
- 保存后设置页列表主标题和知识库页 / 创作页模型分组会使用用户最终选择的 provider。
