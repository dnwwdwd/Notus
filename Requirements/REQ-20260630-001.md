# REQ-20260630-001 侧边栏与 Agent 接入文件/目录操作预览

> 2026-07-02 更新：本条中的“侧边栏统一进入 Diff 预览”口径已由 `REQ-20260702-003` 调整。当前版本仅 Agent `preview_file_operations` 保留预览链路；侧边栏文件树中的目录新建/重命名/删除和文件移动改为直接应用。

## 类型

功能需求

## 背景

侧边栏需要补齐常见文件管理能力，并且不能绕过 Notus 已有的可审查写入机制。Agent 也需要具备整理工作区结构的能力，但删除目录和文件风险更高，暂不开放给 Agent。

## 需求

1. 侧边栏右键支持移动文件。
2. 侧边栏右键支持新建目录、删除目录和重命名目录。
3. Agent 支持移动文件、新建目录、重命名目录和移动目录。
4. Agent 不支持删除目录或删除文件。
5. 以上文件/目录变更都必须接入 Diff 预览组件，支持应用和回滚。
6. Agent 自动确认模式自动应用文件/目录操作；手动确认模式保留待应用状态，由用户在 DiffDialog 中处理。

## 实现结果

1. 新增文件系统 patch 类型：`create_folder`、`rename_folder`、`move_folder`、`move_file`、`delete_folder`。
2. 侧边栏右键菜单区分文件和目录：
   - 文件：移动文件、重命名、删除。
   - 目录：新建目录、重命名目录、删除目录。
3. 侧边栏目录新建、目录重命名、目录删除和文件移动都会先调用 `/api/files/operations` 生成预览，再通过 `FileOperationDiffDialog` 应用或回滚。
4. Agent Loop 新增 `preview_file_operations` 工具，接入现有 operation set、自动确认和手动确认逻辑。
5. Agent 删除目录/文件不开放；工具执行时收到删除类操作会返回 `DELETE_NOT_SUPPORTED`。
6. 目录删除预览会携带 Markdown 文件快照，已应用后可在预览窗口回滚恢复。

## 验收

- 右键文件选择移动后，先出现 Diff 预览，点击应用后文件移动，点击回滚后恢复原路径。
- 右键目录新建/重命名/删除时，先出现 Diff 预览，应用后文件树刷新。
- 已应用的目录删除可以通过预览窗口回滚恢复 Markdown 文件。
- Agent 自动确认模式下，文件/目录操作自动应用并保留回滚入口。
- Agent 手动确认模式下，文件/目录操作保持待确认，用户可逐项应用或回滚。
- Agent 无法删除目录或文件。
