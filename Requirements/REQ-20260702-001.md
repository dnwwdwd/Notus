# REQ-20260702-001 LLM 配置改为提供商展示并按提供商分组模型

## 类型

功能优化

## 背景

当前 LLM 配置列表和新增/编辑弹窗仍保留“配置名称”概念，而知识库页与创作页的模型下拉虽然有分组结构，但分组标签混入了协议语义，第三方 Anthropic 兼容配置会被统一归到 `Anthropic`，不利于按真实提供商管理模型。

## 需求

1. LLM 新增/编辑弹窗不再要求用户填写“配置名称”，改为展示系统自动识别的“提供商”。
2. LLM 列表主标题改为提供商，元信息只保留模型名和 Base URL，不重复展示同一提供商标签。
3. 知识库页与创作页的模型下拉必须按提供商分组，而不是按兼容协议分组。

## 实现结果

1. 设置页与引导页共用的 LLM 配置弹窗已移除“配置名称”输入，改为只读“提供商”字段，并根据 Base URL 与模型名自动识别。
2. LLM 列表主标题改为提供商展示，保留模型名和 Base URL 作为补充信息。
3. AgentWorkspace 的模型分组标签已统一改为 `resolveLlmProviderLabel(config.provider)`，第三方 Anthropic 兼容接口不会再被协议分支强制显示为 `Anthropic`。

## 验收

- 新增或编辑 LLM 配置时，不再需要手填“配置名称”。
- LLM 列表中每条配置主标题显示提供商。
- 知识库页和创作页的模型下拉按提供商展示分组标题。
