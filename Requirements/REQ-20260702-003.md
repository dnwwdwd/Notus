# REQ-20260702-003 调整侧边栏与 Agent 文件系统操作确认边界

## 类型

功能优化

## 背景

当前侧边栏文件树与 Agent 文件系统操作共用了同一套“先生成 Diff 预览，再手动应用”的交互口径。实测后发现这条边界不符合真实使用预期：

1. 侧边栏右键菜单本质上是用户自己显式执行的文件管理动作，不需要再走额外的预览确认弹窗。
2. Agent 的文件/目录操作仍然属于 AI 代执行，手动确认模式必须保留可审查的 Diff 预览。
3. 现有 AgentWorkspace 对 `preview_file_operations` 的目录重命名、文件移动等路径型 patch 渲染不完整，手动模式下很难看清实际变更。

## 需求

1. 侧边栏文件树中的结构性操作改为直接应用，不再弹出 `FileOperationDiffDialog`：
   - 新建目录
   - 重命名目录
   - 删除目录
   - 移动文件
2. Agent 的 `preview_file_operations` 保持现有确认边界：
   - 自动确认模式：Loop 完成前自动应用
   - 手动确认模式：保留消息摘要卡和 `DiffDialog`，由用户逐项应用或回滚
3. Agent 手动确认模式下，目录重命名、移动文件、移动目录、新建目录、删除目录必须在详情弹窗中正确展示路径 diff 或目录快照，不能再出现“有预览卡但 diff 为空白”的情况。

## 实现结果

1. 侧边栏右键菜单中的目录新建、目录重命名、目录删除和文件移动，已改为直接调用 `/api/files/operations` 的 `apply` 分支；成功后立即刷新文件树，不再生成预览弹窗。
2. `AgentWorkspace` 的文件级详情弹窗已补齐文件系统 patch 渲染逻辑，`preview_file_operations` 现在会展示：
   - `create_folder`：新增目录路径
   - `rename_folder` / `move_folder` / `move_file`：原路径 / 新路径
   - `delete_folder`：目录路径和快照中文件列表
3. 当前产品口径已同步调整：侧边栏文件树直接应用，Agent 继续保留预览和自动/手动确认分界。

## 验收

- 侧边栏右键新建目录、重命名目录、删除目录、移动文件时，不再弹出 Diff 预览，操作成功后直接刷新文件树。
- Agent 自动确认模式下，文件/目录操作仍会自动应用并保留详情查看与回滚入口。
- Agent 手动确认模式下，`preview_file_operations` 的详情弹窗能看到完整的路径变更 diff 或目录快照，不再出现空白详情。
