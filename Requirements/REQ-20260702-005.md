# REQ-20260702-005 统一 LLM 协议下拉与聊天输入框多行体验

## 分类

用户体验优化

## 背景

当前设置页 LLM 新增/编辑弹窗中的“兼容协议”字段单独使用了原生 `select`，没有复用项目现有的共享下拉组件，导致交互和视觉风格与其他表单项不一致。与此同时，知识库页和创作页的底部输入框虽然使用了 `textarea`，但多行输入时增高行为不稳定，用户更容易感知为“只有一行高，超出后直接在框内滚动”。

## 需求

1. LLM 新增/编辑弹窗中的“兼容协议”字段改为复用项目共享的下拉组件，而不是单独使用原生 `select`。
2. 知识库页和创作页的聊天输入框默认保持单行高度。
3. 当输入内容换行后，输入框需要自动增高并显示多行内容。
4. 输入框最大高度限制在约 5 行文本；超过后只在输入框内部出现纵向滚动，不继续撑高整个底栏。

## 实现摘要

1. `LlmConfigCardsSection` 的“兼容协议”字段已改为复用共享 `DropdownSelect`，并沿用当前弹窗的暖色表单风格。
2. `InputBar` 新增统一的 textarea 自适应高度逻辑，按实际 `line-height` 动态计算最大高度。
3. 知识库页和创作页底部输入框现在默认单行，换行后会自动增高，最高约 5 行，超过后切换为输入框内部滚动。

## 验证

- 设置页新增/编辑 LLM 配置时，“兼容协议”字段展示为项目共享下拉组件。
- 知识库页和创作页输入短文本时保持单行高度。
- 连续输入多行文本时，输入框会自动增高。
- 超过约 5 行后，输入框不再继续撑高，而是出现内部滚动。
