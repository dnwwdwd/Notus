# REQ-20260709-001：侧边栏文件树支持移动目录

## 分类

功能优化

## 背景

侧边栏文件树已支持文件移动、目录新建、目录重命名和目录删除，但目录右键菜单缺少“移动目录”。用户显式管理文件树时，应能直接把目录移动到其他目录下，并保持侧边栏操作直接应用、不进入 Agent DiffDialog 的既有边界。

## 需求

1. 目录右键菜单新增“移动目录”入口。
2. 移动目录复用侧边栏直接应用链路，成功后刷新文件树。
3. 移动目标列表不得包含当前目录及其子目录，避免把目录移动进自身。
4. 文件移动入口保持不变，继续使用同一个移动弹窗。
5. 目录重命名、目录移动、目录删除等侧边栏显式文件管理动作不进入 DiffDialog。

## 实现记录

1. `notus/components/Layout/Sidebar.js` 将移动弹窗泛化为文件/目录两用。
2. 目录右键菜单新增“移动目录”，提交时生成 `move_folder` 文件系统操作。
3. 移动目录时过滤目标目录选项，排除自身和所有子目录。
4. 目录重命名按钮文案从“生成预览”修正为“确认”，与侧边栏直接应用口径一致。
5. `notus/tests/ui-bug-regressions.test.js` 增加侧边栏移动目录和提示词边界的静态回归断言。

## 验收

- 右键目录可以选择“移动目录”。
- 移动目录弹窗显示目录路径和目标目录下拉。
- 目标目录不包含当前目录及其子目录。
- 确认后调用 `/api/files/operations` 的 `apply` 分支并刷新文件树。
- 文件移动、目录重命名、目录删除仍保持直接应用。
