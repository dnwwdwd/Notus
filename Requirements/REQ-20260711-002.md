# REQ-20260711-002 图床设置页

## 分类与目标

- 分类：用户体验优化。
- 状态：已完成。
- 目标：将图片上传位置与对象存储参数从个性化页拆出，避免工作区偏好和云端凭据混在同一页面。

## 已实现规则

1. 设置导航新增“图床”，路由为 `/settings/image-storage`。
2. 图床页使用同一组选项选择图片上传位置：本地资源目录、腾讯云 COS、阿里云 OSS、Cloudflare R2。
3. 选择本地时只展示本地行为说明；选择云端服务时展示该服务所需的 Bucket、Region/Endpoint、公开 URL、前缀与密钥字段。
4. 个性化页只保留标题与文件名绑定、默认编辑器展开和默认 AI 面板展开。
5. 设置数据模型、密钥脱敏规则和图片上传 API 不变。
