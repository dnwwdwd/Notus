# REQ-20260714-001 提问卡片导航与 Agent 输入区布局优化

## 分类与目标

- 分类：用户体验优化。
- 状态：已完成。
- 目标：减少提问卡片底部导航的文字占用，并让 Agent 输入区不遮挡 AI 消息操作。

## 已实现规则

1. 提问卡片的“上一题”和“下一题”改为仅显示左右箭头 icon，保留 `aria-label`、tooltip 和禁用态。
2. 卡片处于答题阶段时，焦点不在文本输入框内可用左、右方向键切换上一题和下一题；右方向键仅在当前题已回答时生效。
3. Agent 输入框保持默认 5 行文字高度，输入容器宽度固定为父容器的 95%；消息滚动区为固定高度输入框预留底部空间，AI 消息的复制和重试操作可完整显示。

## 验证

- `npm --prefix notus run lint`
- `npm --prefix notus run build`
