# REQ-20260716-001：文件编辑器拆分文章标题与正文编辑区

## 分类

用户体验优化。

## 需求

文件页富文本编辑器采用类似语雀的两段式结构：顶部为独立的文章标题输入区，下方为正文富文本编辑区。

`id`、`created_by`、`title` 等 Notus 内部 Frontmatter 不属于可见编辑内容，不能出现在标题或正文区域。用户自定义 Frontmatter 的编辑与展示边界需要在实施时单独明确，避免误删。

## 当前状态

已完成。

## 实施边界

- 标题输入区保存为 Markdown 一级标题，并继续参与现有标题—文件名联动设置。
- 正文编辑继续使用现有 Tiptap 富文本编辑器。
- 保存时保留稳定 `id` 和 Agent 创建来源等系统元数据。
- `BUG-20260716-002` 已修复：Agent 创建文件的系统 Frontmatter 不再进入标题或正文。
