# REQ-20260716-003：Agent 图片输入、会话媒体配额与目录 Mention 优化

## 分类

功能优化 / 用户体验优化。

## 交付

- Agent 输入区新增独立图片入口，支持 PNG、JPG、JPEG、WEBP、GIF；图片和解析附件按用户上传顺序混排为同一组 chip，图片不计入附件。
- 单条消息最多 30 张图片，单个对话累计最多 50 张；单条消息最多 10 个解析附件，单个对话累计最多 20 个。
- 图片临时保存后仅注入当前 Agent 轮次。OpenAI Chat Completions 请求使用 `image_url` data URL；Anthropic Messages 请求使用 base64 `image` block。
- Anthropic 图片输入额外遵守单请求体积边界：原始图片总大小最多 20MB，避免 base64 编码后超过其 32MB 请求限制。
- 历史会话恢复时，图片缩略图与附件继续按上传顺序显示。
- `@` 候选同时列出工作区文件和目录。候选主行只显示名称，次行只显示相对路径。
- 选择目录后插入 `@{folder:相对路径}`。Agent 必须先分析该目录，再按任务读取少量文件或在该目录范围内检索；不会因目录引用扫描整个工作区。
