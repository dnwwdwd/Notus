# REQ-20260717-003：AI 输入草稿与待发送媒体浏览器端持久化

## 分类

功能需求 / 用户体验优化。

## 需求

AI 输入框中尚未发送的文本、文件 Mention、图片和解析附件需要在浏览器端长期保存。刷新页面、重新打开桌面端 WebView 或暂时离开文件工作区后，用户可以继续编辑这份草稿。

## 交付

- 使用 IndexedDB 保存输入文本、`mention_segments`、Mention 元数据以及待发送图片/文件的 Blob 和上传顺序。
- 页面重新加载时恢复文本与 Mention 卡片的原始交错顺序，重建待发送 `File` 对象和图片预览 URL。
- 用户移除附件、图片或 Mention 后同步更新浏览器草稿；发送成功后清空草稿。
- 图片和文件仍只在发送时上传到服务端，浏览器草稿不会提前创建会话媒体记录。
- 上传或 Agent 请求失败时保留待发送媒体，并恢复本轮发送前的文本和 Mention。
- 不设置过期时间；用户清空并发送成功后才删除对应浏览器草稿。

## 技术边界

- 持久化范围是当前 Agent 输入区的未发送草稿，不替代服务端历史会话保存。
- IndexedDB 不可用或读取失败时不阻断 AI 输入和发送流程；恢复失败只影响本地草稿恢复。
- 浏览器端保存的 Blob 与当前浏览器用户数据一起受浏览器清理策略管理，不上传到服务端，也不跨浏览器同步。
