# REQ-20260722-004：文件工作区逐级收起响应式布局

## 分类与状态

- 分类：功能优化 / 用户体验优化
- 状态：已完成

## 目标

让 Web 和桌面端在窗口缩小时依次收起文件树和富文本编辑器，AI 面板始终保留为主工作区，不把编辑器和 AI 面板改为上下排列。

## 实现

1. 宽度低于 960px 时，文件树切换为 40px 入口和可展开抽屉。
2. 宽度低于 760px 且编辑器、AI 面板同时打开时，由持久化面板状态与视口状态共同派生富文本编辑器收起；编辑器宽度、分隔线和透明度过渡到零，AI 面板同步扩展并保持展开。
3. 移除 900px 时将双栏布局改为纵向排列的样式覆盖；中等宽度保留横向分栏与拖动能力。
