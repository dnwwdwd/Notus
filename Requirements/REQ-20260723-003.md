# REQ-20260723-003：图片识别结果持久化为 Agent 对话上下文

## 分类与状态

- 分类：功能优化
- 状态：已完成

## 目标

把 Agent 对话图片的识别结果作为可持久化的来源文本，与 PDF、Word、Markdown、文本和网页解析结果明确分类。后续同一对话直接使用这段图片摘要，不再让模型自行决定是否调用历史图片工具。

## 实现

1. 用户消息落库后，服务端使用当前视觉模型对本轮图片执行一次独立识别，输出主体、可读文字、界面状态、数据和不确定项的简洁事实摘要。
2. 识别成功后，以 `image_recognition` 类型写入 `messages` 表的来源记录，并保存对应 `notus-conversation-image` 受控引用；该类型与解析附件、网页内容共用持久化和上下文预算层，但在提示中使用“图片识别结果”分类标题。
3. 同一对话的每次 Agent 任务自动加载这段分类文本。识别成功后，主 Agent 不再重复提交本轮图片 Base64；历史图片也不再通过工具重新注入视觉上下文。
4. 移除 `list_conversation_images`、`read_conversation_images` 的 Agent 工具定义、执行器和提示词规则。图片识别失败不伪造摘要，当前轮保留原有视觉输入作为兜底。
