## 已实现范围

1. Agent 新增 `install_skill_from_git`，只接受无凭据 HTTPS Git 仓库地址，复用 `main` / `master` 回退、根目录 `SKILL.md` 校验和受管安装事务；同名 Skill 默认拒绝覆盖。
2. Agent 新增 `add_mcp_server`，创建后立即测试连接并缓存工具。HTTP MCP 在全部运行环境可用；stdio 只在 Electron 桌面端出现在工具定义中，服务端仍会拒绝其他运行环境的绕过调用。
3. 新增 MCP Server 名称在当前用户范围内不允许重复。连接测试失败时保留已保存配置，结果明确标记为测试失败。
4. Agent 传入的 HTTP Header 与 stdio 环境变量统一按密钥保存。工具输入日志、工具结果、SSE 摘要和回执只保留字段名称与配置状态；用户选择保留原始对话内容，故聊天消息仍可能含有用户主动提供的密钥文本。
