# REQ-20260727-001：全局 Agent 文件服务与受控长期记忆

- 日期：2026-07-27
- 分类：功能需求
- 状态：已完成

## 目标

为 Notus Agent 增加跨会话生效的 `soul.md`、`style.md`、`memory.md`。文件正文保存在应用数据目录，是唯一内容来源；第一阶段不增加其他 Agent 文件或记忆向量库。

## 已实现

- Web、Electron、懒猫通过平台路径层统一使用 `<dataRoot>/agent`，历史快照保存于 `agent/history/<file>/`；Electron 另提供固定 IPC 打开目录。
- 文件服务负责缺失补建、UTF-8/大小/符号链接校验、原子保存、Hash 冲突、有限完整快照、恢复默认、回滚和外部编辑缓存失效。
- 设置页提供三份 Markdown 源码编辑、保存/取消、恢复默认、字符提示、更新时间、历史查看与回滚。
- Prompt 固定按安全规则、Notus 指令、`soul.md`、相关 `memory.md`、任务材料、写作任务的 `style.md`、Skill/MCP、当前用户请求组织。用户文件不能扩大工具权限或改变确认边界。
- Agent 可读取固定文件枚举；更新必须带预期 Hash，且仅在用户明确要求记住、长期调整写作方式或调整人格时执行。

## 验证

- `npm --prefix notus run test:global-agent-files`
- `npm --prefix notus run test:platform`
- `npm --prefix notus run lint`

## 边界

`memory.md` 的主动候选只允许 Agent 提建议；一次性任务、临时语气和未明确的偏好不会写入长期文件。
