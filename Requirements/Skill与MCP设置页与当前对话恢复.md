# Skill与MCP设置页与当前对话恢复

## 分类

功能优化 / 用户体验优化

## 需求

1. 以具有实际含义的图标替换 Skill、MCP 和快捷键入口中的通用星光、插头与省略号图标。
2. 重新设计 Skill 与 MCP 设置页，使其与现有暖白设置页一致；界面统一使用单数“Skill”，去除页面顶部的说明段落。
3. 文件工作区在应用重新打开后恢复此前正在查看的 Agent 对话。

## 实现

- 新增书册星标 Skill、双节点 Server MCP、键盘三种描边图标，并替换设置导航、设置页、输入区、Mention 和 MCP 授权卡中的对应图标。
- Skill 和 MCP 均采用资源卡：标题行显示资源图标、数量和操作；资源行展示状态、元信息与操作，窄宽度时自动换行。
- 当前文件工作区把有效的对话 ID 保存到浏览器本地存储。首次读取历史列表后仅在该 ID 仍存在时载入会话；会话被删除、用户新建对话或详情读取失败时清除记录。

- `npm --prefix notus run test:skill-mcp`
