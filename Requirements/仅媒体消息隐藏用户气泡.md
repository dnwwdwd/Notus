# 仅媒体消息隐藏用户气泡

## 分类与状态

- 分类：用户体验优化。
- 状态：已完成。
- 对应台账：`REQ-20260813-003`。

## 需求范围

当用户只上传解析附件或图片、未输入文字且未插入 Mention 时，Agent 仍要收到现有默认任务文本并正常创建会话、解析媒体、执行工具和保存历史；聊天消息流不显示该内部默认文本的用户消息气泡。媒体 chip、消息时间、Agent 工具链和最终回复继续显示。

## 影响分析

| 维度 | 结论 |
|---|---|
| 写入入口 | `AgentInput` 检测仅媒体提交并写入 `hide_user_message_bubble`；默认任务文本仍是 Agent 的输入，不改附件上传和会话创建。 |
| 读取与恢复 | `FileAgentWorkspace`、`useAgentLoopController` 与 `/api/agent/loop/start` 传递并持久化该字段；历史会话映射保留 `meta`，刷新后仍隐藏气泡。 |
| 失败与取消 | 上传或建会失败仍恢复媒体和草稿；隐藏规则不影响任务、SSE、时间戳、附件预览、取消、重试或历史删除。 |
| 平台与安全 | Web、Electron、懒猫共用同一 React 与 API 链路；不改变附件格式白名单、会话媒体权限或 Prompt 安全边界。 |
| 已检查但不受影响 | 带文字或 Mention 的用户消息仍正常显示与改写；AI 回复、图片预览和附件详情不改变。 |

## 行为验收矩阵

| 场景 | 操作 | 预期结果 | 结果 |
|---|---|---|---|
| 仅解析附件 | 仅选文件后发送 | 仅显示附件 chip、时间和任务记录，不显示“请读取并分析已上传的文件。”气泡。 | 自动化静态验证通过 |
| 仅图片 | 仅选图片后发送 | 仅显示缩略图、时间和任务记录，不显示图片分析默认任务气泡。 | 自动化静态验证通过 |
| 含文字或 Mention | 输入文字或插入 Mention 后发送 | 正常显示用户文字气泡与可改写操作。 | 自动化静态验证通过 |
| 历史恢复 | 刷新后读取同一会话 | 仍按持久化标记隐藏仅媒体任务气泡。 | 自动化静态验证通过 |
