# Agent 个性设置页布局与操作优化

- 需求编号：REQ-20260801-002
- 分类：用户体验优化
- 状态：已完成，待实机回归
- 日期：2026-08-01

## 需求范围

将“Agent 个性”中的三个 Markdown 文件切换收口为与图床设置一致的定宽分段 Tab，删除页内重复的功能说明，重新组织文件状态、Markdown 编辑器和操作按钮。不改变全局 Agent 文件的存储、注入、历史、冲突检测和安全边界。

## 影响分析

- 写入入口：设置页保存、恢复默认和历史回滚仍调用现有 `/api/settings/agent-files/*` 接口，不增加新写入路径。
- 读取方与刷新：列表元数据、当前文件和历史版本仍由原 API 读取；切换 Tab 和写入成功后立即刷新。
- 失败与取消：保存失败时保留编辑内容；“取消修改”重新读取服务端内容；恢复默认与回滚继续保留确认步骤。
- 平台与安全：Web、Electron 和懒猫共用同一布局；只有 Electron 显示“打开所在位置”。不改变文件路径校验、历史和 Prompt 权限。
- 已检查但不受影响：Agent 循环的 Prompt 注入、MCP、Skill、图床服务商配置、文件删除能力。

## 行为验收矩阵

| 用户入口 | 行为 | 验收结果 |
|---|---|---|
| Agent 个性设置 | 切换 Agent 性格、写作风格、全局记忆 | 定宽 Tab 稳定显示，只加载当前文件，窄屏不溢出 |
| 编辑器 | 修改 Markdown 并保存 | 按钮有 loading/disabled 反馈，保存后 Hash、时间和字符数刷新 |
| 编辑器 | 取消未保存修改 | 恢复服务端最新内容，不创建历史版本 |
| 编辑器 | 恢复默认 | 确认后写入默认内容，当前内容可从历史恢复 |
| 历史版本 | 查看或回滚 | 保留原有预览、并发 Hash 检查和新版本记录 |
