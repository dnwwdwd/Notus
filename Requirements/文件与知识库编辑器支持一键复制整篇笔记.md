# 文件与知识库编辑器支持一键复制整篇笔记

## 分类

功能需求

## 需求描述

文件页与知识库页左侧文章编辑区需要提供“一键复制整篇笔记”能力，复制结果要尽量保留笔记原有结构，并且在粘贴到外部富文本目标时同时带出正文里的图片。

## 实现要求

1. 文件页与知识库页共用的编辑器工具栏新增“复制全文” icon 入口。
2. 复制时优先写入富剪贴板，至少同时提供 `text/html` 与 `text/plain` 两种格式。
3. 当前笔记中的本地图片需要转成可随剪贴板携带的内嵌图片内容，不能只复制成依赖当前工作区地址的预览链接。
4. 当前环境不支持富剪贴板时，至少回退复制 Markdown 文本，并向用户明确提示图片未写入剪贴板。

## 落地记录

1. 新增 `notus/utils/editorClipboard.js`，负责导出整篇编辑器内容、清理编辑器专用 DOM、把本地图片转成 data URL，并写入 `text/html + text/plain` 剪贴板。
2. `notus/components/Editor/EditorToolbar.js` 新增“复制全文” icon，文件页与知识库页共用同一入口；复制成功后 icon 会短暂切换为已复制态，3 秒后恢复。
3. 复制成功时提示“已复制全文，包含文字和图片”；富剪贴板不可用或写入失败时回退为 Markdown 文本复制，并给出明确警告提示。
4. 新增 `notus/tests/editor-copy-all-support.test.js` 约束复制入口、富剪贴板链路和本地图片判断逻辑。

## 验证

1. `node notus/tests/editor-copy-all-support.test.js`
2. `node --check notus/utils/editorClipboard.js`
3. `node --check notus/components/Editor/EditorToolbar.js`
