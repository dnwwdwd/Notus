# 文件工作区整合AI Agent与文件提及

## 分类与目标

- 分类：功能需求、功能优化、用户体验优化。
- 状态：实施中。
- 目标：将 Notus 收口为单一文件工作区。用户可以只打开 AI 对话，也可以在同一页面并排编辑 Markdown 文件和与 Agent 协作。

## 已确认的产品规则

1. `/files` 是唯一的主工作区。知识库页和创作页不再作为产品入口；顶部不再展示文件、知识库、创作导航。
2. 文件页左侧保留富文本编辑器，右侧承载原创作页的 Agent 输入与对话工作台。两栏仍可拖动调整宽度。
3. AI 面板可以在未选中文件时独立使用。Agent 不再把“当前打开文档”当作隐式任务目标或主动读取对象。
4. `@` 用于查找、选择和引用工作区文件。候选项展示文件名与相对路径；输入按文件名、标题和路径模糊匹配。插入后使用可解析的文件路径引用。
5. Agent 对显式 Mention 的文件按需使用 `read_file` 获取全文；未 Mention 时，由 Agent 根据用户意图决定是否用目录分析、知识检索或文件读取工具定位目标，不强制调用。
6. 顶部右侧提供编辑器和 AI 面板两个展开/收起 icon。默认展开值由个性化设置提供，用户手动切换后持久化；切换不同文件不重置当前状态。再次点击当前选中文件会清除当前文件选中状态，AI 面板状态不变；具体交互由 `REQ-20260711-003` 收口。
7. “复制全文”复制 Markdown 源文本，不将本地图片转为 Base64；富文本 HTML 剪贴板仍可保留渲染结构。

## 实施方案

1. 抽取文件页 Agent 面板，复用既有 `AgentWorkspace`、Agent Loop、会话、预览与附件链路；新任务将工作区根目录作为可操作范围，不附带已打开文件或画布块快照。
2. 复用 `ResizableLayout`，新增工作区布局与面板可见性本地持久化；将个性化页默认展开偏好保存到设置 API。
3. 移除编辑器工具栏的“AI 创作”入口、画布块 Mention 和 Agent Loop 中 `preview_canvas_blocks` 的可用工具定义。
4. 将 `/knowledge`、`/canvas` 改为兼容跳转，保留历史路由不会落入旧产品界面。
5. 同步更新 PDD、PRD、UI Guide、业务流程文档和项目进度，清理旧双页面产品口径。

## 验收重点

- 未打开文件时可以新建对话、发送任务、调用工作区工具与查看结果。
- 打开文件后可同时编辑、聊天、拖动分栏；切换文件不会重置两个面板的手动开关状态。
- `@` 候选能按文件名和路径匹配，候选显示文件名和路径，所选路径能被 Agent 用 `read_file` 精确读取。
- 顶部没有产品页面导航，两个面板开关及个性化默认值符合规则。
- 复制含图片 Markdown 时，`text/plain` 内容不包含图片 Base64。
