# 文件树目录导入导出与任务修订摘要优化

## 分类与状态

- 分类：功能需求 / 用户体验优化。
- 状态：已完成（自动化与本地 Web 验证）。
- 对应台账：`REQ-20260813-002`。

## 背景与目标

文件树已有批量 Markdown 导入和全局文件导出能力，但目录右键不能把 Markdown 导入到目标目录，也不能将该目录及其全部子目录的 Markdown 与图片打成 ZIP 下载；单个文件也缺少直接下载入口。与此同时，Agent 的任务级累计 Diff 卡需要以更紧凑、可理解的摘要表达修订数量和批次状态。

本需求新增目录级上传与导出、文件下载，并把任务修订卡统一成“x 个文件修订”的主描述和可读的状态次描述；不改变既有右键菜单中原有操作的排序。

## 范围与非目标

### 范围

- 目录右键菜单最下方新增“上传文件”“下载目录”。“上传文件”沿用现有 Markdown 导入范围，上传目标为当前目录；目录下载包含当前目录与所有子目录的 Markdown，以及导出功能已有的图片资源，产物为 ZIP。
- 文件右键菜单最下方新增“下载文件”，直接下载该 Markdown 源文件。
- 复用既有导入冲突策略、写入、增量索引与刷新机制；复用既有导出 ZIP 的文件名编码和图片归档约束。
- 累计 Diff 卡图标改为圆形，主描述为“x 个文件修订”，次描述同时列出已应用、已回滚、已废弃和图片变更数量。

### 非目标

- 不增加非 Markdown 文件的上传能力，不开放文件或目录删除的新入口。
- 不改变全局“导出文件”弹窗的选中文件排序、内容或已有入口。
- 不修改 Agent 写入、确认、回滚或图片存储规则。

## 影响分析

| 维度 | 已确认内容 |
|---|---|
| 写入入口 | 目录上传调用既有 `/api/files/import`，继续由 `saveFileByPath()` 落盘并调用 `indexFileWithFallback()`；不新建第二套文件写入逻辑。 |
| 读取方与状态传播 | Sidebar 选择的目录路径传给导入弹窗；导入成功后刷新文件树、`@` 文件/目录候选、当前文件缓存和搜索索引。目录/文件下载经文件 API 读取受 `resolveInside()` 约束的资源。 |
| 失败、取消与安全边界 | 上传沿用 skip/overwrite 与逐文件 SSE 结果；下载仅接受规范化的工作区相对路径，拒绝目录穿越。ZIP 只含选定目录范围内 Markdown 和导出功能已有图片资源，响应头使用 RFC 5987 文件名编码。 |
| 平台边界 | Web、Electron、懒猫均使用 Next 服务端文件 API 与浏览器下载；不在 UI 业务代码判断运行平台。 |
| 已检查但不受影响 | 全局导出弹窗、编辑器保存、外部 MCP 写入、知识库对话与对象存储上传流程不改变。 |

## 行为验收矩阵

| 场景 | 前置条件 | 操作 | 预期结果 | 验证状态 |
|---|---|---|---|---|
| 目录上传 | 右键一个目录，选择多个 `.md` | 选择“上传文件”并确认导入 | 文件以该目录为父路径保存，按冲突策略处理，逐文件索引并刷新树。 | Browser 通过 |
| 目录 ZIP 下载 | 目录及子目录含 Markdown 和图片引用 | 选择“下载目录” | 下载 ZIP，包含目录递归 Markdown 与导出功能已有图片资源；不包含目录外 Markdown。 | Browser 已触发下载且未出现失败提示；接口自动化通过 |
| 文件下载 | 右键一个 Markdown | 选择“下载文件” | 浏览器直接下载原始 `.md`，中文文件名可用。 | Browser 已触发且未出现失败提示；接口自动化通过 |
| 菜单稳定性 | 展开目录和文件右键菜单 | 对比既有项顺序 | 所有旧项顺序不变，三个新入口仅追加在各自菜单最下方。 | Browser 与静态回归通过 |
| Diff 修订摘要 | Agent 有文件、图片、应用/回滚/废弃批次 | 查看累计修订卡 | 图标为圆形；主、次描述符合最新口径；详情仍按需读取。 | 真实 Agent 新建文件后 Browser 通过 |

## 实施与验证

- `Sidebar` 的新入口只追加在原有右键项之后；“上传文件”复用现有 Markdown 导入弹窗并固定导入父目录。
- `/api/files/export` 新增受路径边界保护的目录递归 ZIP 与单 Markdown 下载模式；ZIP 继续归档导出功能已有图片资源。
- 累计 Diff 详情路由补齐 `session_read` capability / session token 校验，并返回任务级变更集详情。
- Browser 在 `http://127.0.0.1:3000/files` 完成目录上传、目录/文件下载入口和真实 Agent 新建文件后的累计 Diff 详情回归；临时目录、文件和测试对话均已删除。
