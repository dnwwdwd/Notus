# 知识库页与创作页共用联网搜索偏好

## 分类

功能优化

## 需求描述

知识库页和创作页右侧 AI 输入框中的联网搜索开关与搜索服务商选择应使用同一份偏好状态，不再按页面分别保存。

## 实现要求

1. 联网搜索开关和搜索服务商保存为一份浏览器本地偏好。
2. 用户在知识库页或创作页任一页面切换联网状态或搜索服务商后，另一个页面重新进入时应使用同一状态。
3. 保留旧本地偏好结构的兼容读取，避免升级后已有用户状态直接丢失。

## 落地记录

1. `notus/utils/agentInputPreferences.js` 改为读写单一偏好对象 `{ webSearchEnabled, searchProvider }`。
2. 读取时兼容旧结构中的 `shared / canvas / knowledge` 字段，优先使用 `shared`，再回退到旧页面作用域值。
3. `AgentWorkspace` 不再接收页面级 `preferenceScope`，知识库页和创作页都直接读取同一份偏好。

## 验证

1. `node --check notus/utils/agentInputPreferences.js` 通过。
2. `node --check notus/components/AgentWorkspace/AgentWorkspace.js` 通过。
3. `node --check notus/pages/knowledge.js` 通过。
4. `node --check notus/pages/canvas.js` 通过。
5. `npm run lint:web` 通过。
6. `npm run build:web` 通过。
