# 设置弹窗、图床选择与提示统一

## 分类与目标

- 分类：功能优化 / 用户体验优化。
- 状态：已完成。
- 目标：将设置保留在当前工作区之上完成，明确图片区分“选择上传位置”和“维护图床参数”，并统一提示交互。

## 已实现规则

1. 顶栏、AI 配置引导与日志入口均在当前界面打开设置弹窗；点击遮罩不会关闭，标题栏关闭按钮与 Esc 仍可关闭。
2. 个性化页新增“图片上传位置”行，左侧说明、右侧使用共享 `SegmentedTabs` 选择本地资源目录、腾讯云 COS、阿里云 OSS 或 Cloudflare R2。
3. 本地资源目录可直接切换；任一已配置的云图床可直接设为上传位置。未配置的云图床点击后仍切换 tab，并显示含图床配置链接的提示。
4. 图床页不再提供上传位置选择，统一展示腾讯云 COS、阿里云 OSS、Cloudflare R2 三套独立参数；各服务可单独保存，上传位置仍由个性化页控制。
5. Agent 的“自动 / 手动”确认控件改为复用 `SegmentedTabs`。
6. 全局 `Tooltip` 强制单行、过长省略并根据实际尺寸向视口内偏移；侧边栏文件区按钮提示为“折叠 / 展开”。
7. 设置弹窗不在内部标题栏重复显示“设置”；模型、搜索、日志、个性化、图床、存储、快捷键、关于各页均使用同一条 860px 内容列和同一套页面标题样式。每页顶部只显示标题名称，不显示标题说明文字；个性化页使用与搜索配置相同的全宽设置区。

## 影响范围与验证

- 为每个云图床保存独立的服务端配置；当前上传目标继续同步为既有对象存储运行时配置，密钥不回显。
- 已增加图床配置档案回归测试，覆盖 COS、OSS 的独立读取和旧 R2 配置兼容。
- 页面宽度与标题回归测试要求所有设置页复用 `SETTINGS_CONTENT_MAX_WIDTH` 与 `SettingsPageHeader`，防止后续页面出现不同的最大宽度或标题字样。
