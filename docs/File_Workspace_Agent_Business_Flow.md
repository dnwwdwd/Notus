# 文件工作区 Agent 全流程业务文档

> 更新时间：2026-07-14
> 适用范围：`/files`、`FileAgentWorkspace`、Agent Loop、文件 Mention 和预览应用。

## 1. 入口

用户进入 `/files` 后，右侧 AI 面板可独立使用。选择文件只影响左侧编辑器和 TOC，不为 Agent 自动增加当前文件上下文。

顶部可通过 `Mod+B` 展开或收起富文本编辑器、通过 `Mod+U` 展开或收起 AI 面板；用户可在快捷键设置中调整这两个组合键。

首次从无文件状态打开文件时，个性化设置决定编辑器和 AI 面板是否展开。用户切换已打开文件时，当前开关和分栏宽度保持不变。再次点击当前文件会取消选中，编辑器回到空态，AI 面板和分栏状态保持不变；如果当前内容未保存，先经过离开保护。

文件工作区初始化时读取本地保存的编辑器宽度和 AI 面板宽度；拖动分栏并释放后更新两项宽度。AI 输入区默认保持 5 行文字高度，宽度固定为父容器的 95%；消息列表底部预留输入区高度，回底按钮固定在输入区上方，消息操作不会被覆盖。

## 2. 发送任务

1. 用户在 Agent 输入框输入文本，可上传解析附件或开启联网搜索。
2. 如果富文本编辑器内容未保存，文件页先保存 Markdown。
3. 前端创建 `goal: 用户任务：<输入>`，不传 `active_file_id`，不添加当前文件、路径或块快照。
4. `/api/agent/loop/start` 创建或续写会话，解析本轮附件和 URL，创建 Agent session，再按 SSE 推送过程。
5. `AgentWorkspace` 在执行期间显示工具步骤、流式输出和预览；最终回复仅显示用户可理解的结果与文件变更卡，不展示原始工具调用。通过发送校验后立即清空输入文本；SSE 或 LLM 请求失败时将已有 session 标为 `failed`，输入框恢复可用。

## 3. Mention 文件

1. 用户输入 `@` 或部分名称。
2. 前端从 `allFiles` 搜索文件名、标题和路径，显示文件名与路径。
3. 选择候选后输入框插入 `@{path/to/file.md}`。
4. System Prompt 要求 Agent 把该路径视为明确文件引用；正文需要通过 `read_file` 读取。
5. 若没有 Mention，Agent 只在任务确实需要定位文件或资料时使用 `analyze_folder`、`search_knowledge` 或 `read_file`。

## 4. Agent 工具和预览

- `search_knowledge`：召回语义材料和事实。
- `read_file`：读取完整 Markdown 文件。
- `analyze_folder`：读取实时目录结构，处理新建、移动、重命名目录时优先使用。
- `create_note`、`preview_file_revision`、`preview_patch_files`、`preview_file_operations`：创建可审查写入结果。
- `ask_question_card`：任务明确但缺少结构化信息时暂停并等待用户回答。
- `web_search`：用户开启联网搜索且服务商可用时注册。

删除文件和目录始终不开放。`preview_canvas_blocks` 不在工具定义中。

## 5. 确认、刷新和历史

自动确认会应用通过安全检查的写入；手动确认通过 DiffDialog 逐项应用、废弃或回滚。Agent 可能修改文件后，前端刷新文件树；若当前编辑器文件受影响，清除缓存并重新载入。

历史抽屉支持切换、删除、导出和日志入口。为兼容历史记录，文件工作区的 Agent 会话继续按 `kind=canvas` 读取和保存；用户界面不显示品牌标题，空态使用“你今天在想些什么？”。

## 6. 提问卡片

Agent 调用 `ask_question_card` 后，右侧底部显示 `ClarifyDrawer`，覆盖输入区域。用户提交回答后，答案作为 tool result 续跑同一 session；session token 失效时提示用户重新发起任务。答题阶段的前后题使用箭头 icon，焦点不在文本输入框内时可用左右方向键切题，前进仍要求当前题已回答。

## 7. 编辑器图片上传

图片粘贴和工具栏选图不进入 Agent Loop。它们直接请求图片上传 API，并按独立图床设置写入本地资源目录或对象存储。对象存储成功后，编辑器插入公开 URL；失败时保持当前编辑内容并提示错误，不产生 Markdown 图片引用。

图片预览层挂载到页面根节点，覆盖顶部菜单栏；关闭、计数、图片名称和左右切换按钮始终可操作。

## 8. 编辑器表格插入

工具栏“插入表格”打开弹窗，用户输入行数和列数后创建带表头的可编辑表格。表格节点沿用现有 Markdown 双向转换链路，保存后写回 GFM 表格语法。
