# Notus UI Guide v3.0

> 更新时间：2026-07-14

## 1. 全局 Token

沿用 `styles/globals.css` 的 token：

- 背景：`--bg-primary`、`--bg-secondary`、`--bg-elevated`、`--bg-sidebar`。
- 文字：`--text-primary`、`--text-secondary`、`--text-tertiary`。
- 强调色：`--accent`、`--accent-subtle`。
- 边框：`--border-primary`、`--border-subtle`。
- 字体：`--font-ui`、`--font-editor`、`--font-mono`。

亮色和暗色主题必须只覆盖 token，组件不写运行时主题判断。

## 2. Shell

```text
┌────────────────────────────────────────────────────────────────┐
│ Notus                         保存  搜索  编辑器  AI  设置       │
├──────────┬─────────────────────────────────────────────────────┤
│ Sidebar  │ 文件工作区                                            │
│          │                                                       │
│ 文件树   │ 富文本编辑器                  │ AI 聊天面板           │
│ / TOC    │                                │ 消息 / 工具 / 输入框  │
└──────────┴─────────────────────────────────────────────────────┘
```

- `TopBar` 高度 48px。
- 顶部不显示文件、知识库、创作等导航 tab。
- 工作区页面右侧图标顺序固定为：搜索、富文本编辑器开关、AI 聊天面板开关、设置；设置页面自身不显示重复的设置 icon。搜索不再使用输入框样式，tooltip 为“搜索文件”。
- 编辑器和 AI 面板开关使用带填充层次的拟物化选中 icon；按钮本身不显示外边框和阴影，激活状态使用 `--accent`。
- 搜索、编辑器、AI 面板和设置 icon 的点击区域统一为 32px × 32px；编辑器和 AI 面板默认快捷键分别为 `Mod+B`、`Mod+U`，tooltip 同时展示当前快捷键。
- 页面最小尺寸保持 1360 × 800。

## 3. Sidebar

- 宽度 240px，背景 `--bg-sidebar`，右边界 `1px solid --border-subtle`。
- 文件树与 TOC tab 保留。未打开文件或编辑器收起时，TOC 不可用。
- 文件行选中时使用 `--accent-subtle`。
- 再次点击已选中文件会取消选中，编辑器显示未选择文件空态；AI 面板状态不变。

## 4. 文件工作区 `/files`

### 4.1 面板组合

| 编辑器 | AI 面板 | 页面内容 |
|---|---|---|
| 开 | 开 | 左右分栏，可拖动中线 |
| 开 | 关 | 富文本编辑器占满工作区 |
| 关 | 开 | AI 聊天面板占满工作区 |
| 关 | 关 | 居中提示用户用顶部 icon 展开面板 |

- 两个面板打开时，编辑器默认约占 60%，允许 38%～70%。
- 编辑器最小宽度 560px，AI 面板最小宽度 456px。
- 分隔线宽 4px，hover 为 `--accent-muted`，拖动时为 `--accent`。
- 用户选中文件时，个性化默认值决定首次展开状态；切换另一个文件时保持当前组合和宽度。
- 拖动分栏后同时保存编辑器与 AI 面板宽度，刷新或重新进入文件页时恢复。

### 4.2 富文本编辑器

- 编辑器工具栏高度 40px，位于编辑器面板内部，不跨越 AI 面板。
- 工具栏下方是独立的文章标题输入区；正文富文本编辑器位于其下。Notus 内部 `id / created_by / title` Frontmatter 不显示在这两个区域。
- 保留撤销、标题、文字格式、链接、图片、列表、引用、代码块、清除样式和复制全文。
- 工具栏的“插入表格”按钮打开行数/列数弹窗，默认 3×3，首行为表头，插入后可直接编辑单元格。
- 移除“AI 创作”按钮。
- 正文最大宽度 780px，padding `48px 60px 120px`，使用 `--font-editor`。
- 未选中文件时显示“选择一篇文章开始编辑”，并提示可直接使用右侧 AI。
- 复制全文的提示为“已复制 Markdown 源文本”。

### 4.3 AI 聊天面板

- 面板顶栏高度 48px，不显示左侧品牌 icon 或标题；右侧仅有历史和新建对话 icon。
- 对话区继续使用原 AgentWorkspace 的贴底滚动、工具步骤、diff 对话框、附件内容和消息操作。
- 空态不显示图形或辅助说明，只显示“你今天在想些什么？”。
- 输入框固定在底部，支持模型选择、联网搜索、自动/手动确认和附件。
- 输入框默认约为 5 行文字高度；容器宽度固定为父容器的 95%，居中显示。消息列表底部留出输入区高度，AI 消息的复制和重试操作始终可见。
- 回底按钮位于输入框上方，和输入框之间保留明确间距；任务完成后工具步骤不保留在最终回复中。
- 无文件状态下输入框可用；占位文案为“输入任务，或使用 @ 查找并引用文件…”。
- AI 未就绪时只锁定 AI 面板，编辑器和文件树仍可使用。
- 提问卡片底部的上一题、下一题只显示箭头 icon，并提供 tooltip；答题阶段可用左右方向键切题，焦点位于自定义文本输入框时不拦截方向键。

## 5. 文件 Mention 面板

```text
输入：请总结 @项目计划

┌─────────────────────────────────────────────┐
│ 项目计划                                     │
│ work/项目计划.md                             │
├─────────────────────────────────────────────┤
│ 2026 复盘                                    │
│ archive/2026 复盘.md                         │
└─────────────────────────────────────────────┘
```

- 输入 `@` 立即显示工作区文件候选。
- 候选主行是可见文件名，次行是相对路径；路径不隐藏为内部 id。
- 以标题、文件名和路径做模糊包含匹配，最多显示 8 条。
- 选中后插入 `@{relative/path.md}`。这段文本可见、可编辑，也能表达带空格的路径。
- ArrowUp / ArrowDown 移动，Enter 选择，Esc 关闭；中文输入法组合态不拦截按键。
- 没有匹配项时显示“没有匹配的文件”。

## 6. 个性化页

个性化页提供：

- 标题与文件名双向绑定。
- 默认展开富文本编辑器。
- 默认展开 AI 聊天面板。

默认值下方明确说明：从没有打开文件的状态进入文件时使用；切换已打开文件保持当前状态。

## 7. 图床页

- 设置导航显示“图床”，独立承载图片上传位置和云端参数。
- 上传位置以四个同级选项展示：本地资源目录、腾讯云 COS、阿里云 OSS、Cloudflare R2。
- 选择本地时展示相对路径写入 Markdown 的说明；选择云端服务时展示对应的 Bucket、Region/Endpoint、对象前缀、公开访问基础 URL、Access Key ID 和 Secret Access Key。
- 已保存密钥只显示“已保存”状态；输入框留空表示保持当前密钥，清除操作需要用户显式点击。公开 URL 下方说明该地址会写入 Markdown，不能填写临时签名链接。

## 8. 兼容路由

- `/knowledge` 和 `/canvas` 不显示旧界面，直接跳转 `/files`。
- 所有可见入口、空状态、设置说明和快捷键文案使用“文件工作区”和“AI Agent”，不再引导用户前往知识库页或创作页。
