Notus 已完成从“文件、知识库、创作三页并列”到“单一文件工作区 + AI Agent”的产品形态调整。Web 前端、真实文件系统、SQLite 索引、Agent Loop、附件解析和 Electron 主链路继续可用。

## 当前需求口径

- 富文本编辑器工具栏支持弹窗自定义行列插入 Markdown 表格；侧边栏再次点击当前文档会取消选中并回到编辑器空态。
- 图床设置页已对齐搜索配置页的暖白卡片和分段选项视觉结构。
- 顶部搜索已收敛为 icon；编辑器/AI 面板宽度与 AI 输入区尺寸已支持持久化和自适应。
- 编辑器与 AI 面板开关统一使用 32px 顶栏图标按钮，默认快捷键为 `Mod+B`、`Mod+U`；搜索 icon 提示为“搜索文件”。
- AI 面板已移除顶部品牌标识和空态图形，无消息时仅显示“你今天在想些什么？”。当前版本为 0.1.8。

- 文件工作区是唯一主入口；顶部没有文件、知识库、创作导航。
- 富文本编辑器和 AI 面板可独立展开或收起；同时展开时可拖动调整宽度。
- 关闭窗口后重新打开会恢复上次文档和编辑器、AI 面板开关组合；个性化默认值只用于已运行工作区从无文件状态打开文件。
- AI 面板不依赖当前文件。当前文件只服务编辑器、TOC 和保存。
- `@` 引用工作区文件或目录。输入框和用户消息使用与 prompt 同一文字流的结构化 mention 节点，旧 token 会在读取时兼容转换；Agent 对文件按需调用 `read_file`，对目录先调用精确路径的 `analyze_folder`，不会默认扫描整个工作区。点击卡片可按需预览文件或目录内容。
- Agent 图片输入已接入 OpenAI Chat Completions 和 Anthropic Messages 协议。单条消息最多 30 张图片、10 个解析附件；单个对话最多 50 张图片、20 个解析附件，图片与附件按上传顺序混排。待发送图片可复用笔记图片预览层并在当前队列内切换。
- 当前轮图片直接进入视觉上下文；历史图片只有 Agent 调用会话图片工具后才按需重注入。会话受控引用和临时预览都限定在所属对话内。
- Agent 输入中的文本、Mention、图片和解析附件会长期保存在浏览器 IndexedDB，刷新后恢复；发送成功或清空后清理，浏览器端不设置过期时间。
- 会话图片保存在 `<sessionDir>/images` 并与消息元数据关联；当前不会因会话结束、删除、回滚或笔记应用自动销毁，上传失败的中间文件会清理。
- 用户要求把图片整理进笔记时，目标明确则直接生成预览；目标不唯一时通过提问卡片选择候选、手填已有路径或新建笔记。单选自动推进，全部回答在同一组件中复核。
- 图片新增、移除、替换已进入 operation set 和 DiffDialog。应用预览时复用图床设置写入本地、COS、OSS 或 R2；回滚只恢复 Markdown 引用，不物理删除图片资源。
- Agent 可创建、修改、重命名和移动文件或目录；删除能力不开放；所有写入沿用预览、自动确认、手动确认和回滚边界。
- 复制全文输出 Markdown 源文本，不生成图片 Base64。
- 新图片可按图床设置保存本地或上传 COS、OSS、R2；云端上传失败不插入图片，也不自动回退本地。
- 文件编辑器已拆分标题输入区与正文富文本区；Agent 系统 Frontmatter 不再显示给用户。
- 导入文件标题默认采用文件名；图片预览覆盖顶栏；设置页不再显示重复设置入口。
