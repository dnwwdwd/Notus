## 使用规则

1. 先按功能域阅读“必读文档”，再检查代码与测试入口；实际变更跨行时合并检查。
2. 涉及持久化资源、状态传播、Agent、平台或多个写入入口时，在对应业务名称需求文档中写影响分析和行为验收矩阵；bug 按 `AGENTS.md` 写入 Bug 台账。
3. 新增、归档或合并业务流程文档，或改变一个功能域的主要入口时更新本表；普通函数级改动不需要修改本表。
