# Notus 版本更新记录

## 0.1.11

- AI 输入框和消息列复用父容器 95% 的宽度约束，在独占和双栏布局中同步响应；用户消息气泡保持右对齐与内容宽度上限。
- 统一项目、Web 应用与懒猫包元数据版本为 `0.1.11`，重新生成 `.lpk` 安装包。

## 0.1.10

- 图床配置页改为服务商 Tab，一次只显示当前服务商的参数表单；阿里云 OSS 位于首项并默认选中。
- 同版本修订：图床 Tab 对齐搜索配置，并按当前图片上传位置默认打开对应云服务；本地模式回退至阿里云 OSS。Skill ZIP 导入收敛为拖放/点击上传区，Skill 列表隐藏来源与状态元信息；启停或安装 Skill 后，`@` 候选立即刷新。
- 统一项目、Web 应用与懒猫包元数据版本为 `0.1.10`，重新生成 `.lpk` 安装包。

## 0.1.9

- 统一项目、Web 应用与懒猫包元数据版本为 `0.1.9`，重新生成 `.lpk` 安装包。
- DiffDialog 中的 Markdown 文件路径可直接打开对应文档；文件已删除或已打开时显示提示。
- AI 独占工作区时，消息区宽度与输入框对齐；Tooltip 不再显示快捷键组合。
- Agent 检索改为每来源任务级 3→5 批量查询，原词固定首位；重复或换词调用复用缓存。
- 显式 URL 直连读取状态会保留到最终回复，联网搜索为空只显示“没有补充结果”；聊天消息新增脱敏资料与文件状态卡。
- 写作目标不明确时先用提问卡片确认修改候选文章或新建文章，确认前不写入文件。

## 0.1.4

- 记住侧边栏文件树 / 大纲 tab、各自滚动位置，以及文件页、知识库页、创作页的浏览位置。
- 知识库页和创作页支持删除整条 AI 历史会话。
- 优化创作页 AI 编辑判断，减少把普通讨论误判成直接改正文的情况。
- 统一知识库页和创作页的提问卡片流程，并支持 Agent Loop 通过 `ask_question_card` 主动生成或响应用户 prompt 生成提问卡片。
- 简化关于页版本说明展示样式。
- 修复 `.lpk` 在 Docker 构建链路下容易因空间不足打包失败的问题。

- 版本号升级到 `0.1.3`，重新生成 `.lpk`。
