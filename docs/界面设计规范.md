# Notus UI Guide v3.0

> 更新时间：2026-08-02

## 1. 全局 Token

沿用 `styles/globals.css` 的 token：

- 背景：`--bg-primary`、`--bg-secondary`、`--bg-elevated`、`--bg-sidebar`。
- 文字：`--text-primary`、`--text-secondary`、`--text-tertiary`。
- 强调色：`--accent`、`--accent-subtle`。
- 边框：`--border-primary`、`--border-subtle`。
- 字体：`--font-ui`、`--font-editor`、`--font-mono`。

亮色和暗色主题必须只覆盖 token，组件不写运行时主题判断。

## 2. Shell

```text
┌────────────────────────────────────────────────────────────────┐
│ Notus                         保存  搜索  编辑器  AI  设置       │
├──────────┬─────────────────────────────────────────────────────┤
│ Sidebar  │ 文件工作区                                            │
│          │                                                       │
│ 文件树   │ 富文本编辑器                  │ AI 聊天面板           │
│ / TOC    │                                │ 消息 / 工具 / 输入框  │
└──────────┴─────────────────────────────────────────────────────┘
```

- `TopBar` 高度 48px。
- 顶部不显示文件、知识库、创作等导航 tab。
- 工作区页面右侧图标顺序固定为：搜索、富文本编辑器开关、AI 聊天面板开关、设置；设置以覆盖当前工作区的弹窗展示，遮罩不可关闭。搜索不再使用输入框样式，tooltip 为“搜索文件”。
- 编辑器和 AI 面板开关使用带填充层次的拟物化选中 icon；按钮本身不显示外边框和阴影，激活状态使用 `--accent`。
- 搜索、编辑器、AI 面板和设置 icon 的点击区域统一为 32px × 32px；编辑器和 AI 面板默认快捷键分别为 `Mod+B`、`Mod+U`，Tooltip 只展示操作文案。
- 文件树、全局搜索、Diff 或路由打开文章时，编辑器若已收起，先展开编辑器再显示所选文章；用户不需要再次点击顶部开关。应用启动恢复的文章保留关窗前面板组合。
- 页面不设置固定最小尺寸。宽屏保留现有三栏；960px 以下文件树折叠为 40px 入口，点击后以抽屉覆盖内容区；双栏仍可显示时 AI 面板固定 456px，编辑器压缩剩余空间；760px 以下再收起编辑器与分隔线，AI 面板占满工作区。编辑器与 AI 面板不采用上下排列。窗口拉宽不自动展开文件树或编辑器。

## 3. Sidebar

- 宽屏宽度 240px，1200px 以下收缩为 196px；960px 以下为 40px 折叠入口和最大 280px 的临时抽屉。背景 `--bg-sidebar`，右边界 `1px solid --border-subtle`。
- 文件树与 TOC tab 保留。未打开文件或编辑器收起时，TOC 不可用。
- 文件行选中时使用 `--accent-subtle`。
- 再次点击已选中文件会取消选中，编辑器显示未选择文件空态；AI 面板状态不变。

## 4. 文件工作区 `/files`

### 4.1 面板组合

| 编辑器 | AI 面板 | 页面内容 |
|---|---|---|
| 开 | 开 | 左右分栏，可拖动中线 |
| 开 | 关 | 富文本编辑器占满工作区 |
| 关 | 开 | AI 聊天面板占满工作区 |
| 关 | 关 | 居中提示用户用顶部 icon 展开面板 |

- 两个面板打开时，编辑器默认约占 60%，允许 38%～70%。
- 宽屏编辑器最小宽度 560px，AI 面板最小宽度 456px；窄窗口的双栏阶段，AI 面板固定为 456px，编辑器可压缩至剩余空间；760px 以下收起编辑器并隐藏分隔线，让 AI 面板占满工作区。任一面板收起后不保留透明最小宽度，剩余面板从工作区左边界占满可用宽度，消息列和输入框以该面板居中。自动收起只在窗口缩小时触发，拉宽后保留当前收起状态。
- 分隔线宽 4px，hover 为 `--accent-muted`，拖动时为 `--accent`。
- 关闭窗口后重新打开时，恢复上次选中的文档、编辑器开关、AI 面板开关和分栏宽度。用户在已运行工作区从无文件状态选中文件时，个性化默认值决定首次展开状态；文件树、全局搜索、Diff 或路由选择任何文件都会展开编辑器，AI 面板开关和分栏宽度保持不变。
- 拖动分栏后同时保存编辑器与 AI 面板宽度，刷新或重新进入文件页时恢复。

### 4.2 富文本编辑器

- 编辑器工具栏高度 40px，位于编辑器面板内部，不跨越 AI 面板。
- 工具栏下方是独立的文章标题输入区；正文富文本编辑器位于其下。Notus 内部 `id / created_by / title` Frontmatter 不显示在这两个区域。
- 保留撤销、标题、文字格式、链接、图片、列表、引用、代码块、清除样式和复制全文。
- 工具栏的“插入表格”按钮打开行数/列数弹窗，默认 3×3，首行为表头，插入后可直接编辑单元格。
- 移除“AI 创作”按钮。
- 正文最大宽度 780px，padding `48px 60px 120px`，使用 `--font-editor`。
- 未选中文件时显示“选择一篇文章开始编辑”，并提示可直接使用右侧 AI。
- 复制全文的提示为“已复制 Markdown 源文本”。

### 4.3 AI 聊天面板

- 面板顶栏高度 48px，不显示左侧品牌 icon 或标题；右侧仅有历史和新建对话 icon。
- 对话区继续使用原 AgentWorkspace 的贴底滚动、工具步骤、diff 对话框、附件内容和消息操作。
- 空态不显示图形或辅助说明，只显示“你今天在想些什么？”。
- 输入框固定在底部，支持模型选择、联网搜索、MCP 选择、自动/手动确认、解析附件和图片。
- 模型菜单顶部提供“搜索模型或 Provider”，按模型名和 Provider 模糊过滤并保留 Provider 分组；无结果显示明确空态。自动/手动确认的 tooltip 分别为“自动应用修改”“手动应用修改”。
- 历史对话抽屉标题下提供“搜索对话或消息”；有搜索词但无结果时显示“没有匹配的历史对话”。仍有非终态 Agent 任务的条目在标题右侧显示紧凑时钟状态标记：等待回答、等待确认、可继续、正在执行或等待执行；多项任务显示数量。标记有文字和 `aria-label`，不包含停止、继续或其他控制入口。
- 解析附件入口与图片入口独立。图片在输入区和用户消息内均直接显示为纯缩略图，不显示文件名或大小；已发送图片与解析附件一样独立显示在用户文字气泡上方，不使用气泡背景。两类媒体按上传顺序混排，图片不计入附件数量。已发送消息缩略图始终优先使用服务端确认会话归属后的受控地址，不能在确认后退回临时浏览器对象 URL；点击待发送图片时在输入队列内预览，点击已发送消息图片时在该消息全部图片中预览，均支持左右切换、Esc 与遮罩关闭。用户只发送图片时，默认任务为识别并说明图片内容。
- 图片识别结果不作为聊天卡片单独展示，也不显示为附件 chip。服务端把它保存为同一对话的“图片识别结果”上下文，后续 Agent 可直接依据摘要回答或写入；图片和解析附件在内部来源层保持不同分类。Agent 工具链需单列“查看图片”步骤并展示实际读取图片的受控缩略图，用于说明工具意图和对象。
- Agent 请求失败只显示简短错误说明、HTTP 状态和可选请求编号；不得将 Next.js、网关或服务端返回的 HTML 原文显示在消息区域。
- 输入区明确提示并限制单条消息最多 30 张图片、10 个解析附件；历史对话累计分别最多 50 张图片、20 个解析附件。
- 输入框默认约为 3 行文字高度；输入框和消息列共享 `min(860px, calc(100% - 32px))` 的内容列，独占大屏保持可读行宽，双栏和固定 456px AI 面板仍跟随可用宽度。560px 以下左下为附件、确认方式、联网与 MCP 工具组，右下为模型选择和发送；确认方式、联网和 MCP 的文字逐步收为 icon，保留 Tooltip 或无障碍名称。模型名称可截断，完整名称由不超过视口宽度的 Tooltip 呈现；390px 以下隐藏次要图片添加入口。布局收敛仅使用 160ms 的间距/宽度过渡，并尊重减少动态效果偏好，不重叠也不溢出。用户消息气泡保持右对齐与内容宽度上限。消息列表底部留出输入区高度，AI 消息的复制和重试操作始终可见。
- 每条用户消息和 AI 回复显示到分钟的创建时间。当天只显示“HH:mm”；昨天显示“昨天 HH:mm”；前天到最近 7 个日历日内显示“周几 HH:mm”；更早显示“YYYY-MM-DD HH:mm”。时间与复制等消息操作共用一行并紧邻 icon：用户时间在复制 icon 左侧，AI 时间在重试 icon 右侧；纯图片用户消息在图片行下方沿用该顺序。时间字号保持次级信息。
- 输入框中的未发送文本、Mention、图片和解析附件会在浏览器端长期保存。刷新或重新进入工作区后恢复原有文字流和媒体队列；服务端持久化用户消息并确认创建任务后立即回显本轮 prompt 和图片，再继续附件解析、图片识别与 Agent 调度，同时清理草稿。上传或建会失败则保留。浏览器草稿不显示额外提示，不设置过期时间。
- 当前 Agent 对话 ID 也保存在浏览器端。重新打开应用时，仍存在的会话直接恢复；该 ID 不存在或详情读取失败时静默清除，不显示错误提示。
- 改写已发送消息时，发送按钮始终显示“发送”。提交后立刻锁定编辑态和输入，并将 textarea 替换为包含新 prompt 的用户消息气泡；请求失败才恢复 textarea。后续消息仅以非阻塞动画淡出，服务端实际取消的后续 session 的工具记录、提问卡和草稿同时移除，锚点之前的记录必须保留；不出现等待动画期间仍可输入或“发送中”的状态。
- 回底按钮位于输入框上方，和输入框之间保留明确间距；任务完成后工具步骤不保留在最终回复中。
- 最终助手回复下方按需显示紧凑的“已使用资料 / 文件变更”卡；当前版本由代码开关暂时关闭，恢复开关后才渲染。资料项仅展示标题、URL 或相对路径、状态和短摘要；文件项展示路径与待确认、已应用等状态。卡片不显示完整网页正文、密钥、Cookie 或原始 Prompt，状态由服务端回执生成，不能由模型文案覆盖。
- 无文件状态下输入框可用；占位文案为“输入任务，或使用 @ 查找并引用文件…”。
- 输入框不因 Agent 运行、排队、等待提问、重试或失败而禁用；只在模型未就绪、上传中或内容无效时禁用。普通任务提交后先紧跟用户消息显示“任务已提交，正在准备执行”，待第一条真实事件到达后替换；这不是工具链节点。工具链只渲染 Worker 或工具已持久化的真实动作，不能用“准备上下文”、队列状态或循环轮次等前端/内部阶段填充首屏。记录顶部以可折叠的“正在处理 / 已处理 + 时长”概览呈现；概览右侧固定使用朝右箭头，展开状态由 `aria-expanded` 表达；所有工具行图标统一使用 Notus 主色，折叠时只显示完整动作名与展开箭头，参数和输出只在展开后显示，并分成“调用参数 / 调用结果”两个有独立滚动区的代码块；JSON 使用缩进格式。完成和运行均不得使用对勾或转圈。停止操作只位于正在执行任务的记录头部，继续操作在记录操作区最右侧，模型选择区只保留模型与发送操作。固定宽度或窄屏 AI 面板中，附件操作独立成组，确认方式、联网与 MCP 可换行，模型和发送按钮单独位于下一行；不得通过把工具栏强制为单行横向滚动来维持布局。提问卡位于消息流时间线，不覆盖输入区；已回答卡默认折叠，显示问题、答案和时间。
- 工具链附着在本轮消息中，不使用独立任务节点、N 头像或“Notus Agent”标题。没有真实步骤或流式草稿时不能输出空白容器；尚未形成回复时记录位于该 session 的用户消息之后，形成回复后记录位于该 session 的助手回复正文之前。`queued_resume`、`waiting_retry`、`waiting_model_recovery`、修改预览和提问卡片的记录默认展开，头部显示“需要处理”，用户可直接看到恢复说明与“继续任务”入口；继续和停止必须带该记录的 session ID，不能影响其他任务；`cancelled` 没有恢复入口。
- 历史对话中，全部带持久化运行事件的已完成或未完成 Agent 任务都保留各自工具链。已中断的运行步骤使用停止态，`queued_resume` 在链尾显示“任务已暂停，执行记录已保留”和“继续任务”；只有未形成 final 的任务才在工具链下显示“中断前已生成的回复”。已完成任务只显示正式助手回复，不能将过程草稿误标为中断前回复，也不能由后续 session 覆盖。对不符合当前脱敏协议的旧 `run_logs`，只显示工具名称和固定隐私摘要，不展示原始输入或结果。
- `@` 文件和目录引用是可选项。用户只输入普通任务文字、上传图片或解析附件时也可以发送；删除任一 mention 后，输入光标继续可用。
- AI 未就绪时只锁定 AI 面板，编辑器和文件树仍可使用。
- Agent 正在运行、等待提问卡片回答或正在提交回答时，AI 面板不允许通过顶部按钮或 `Mod+U` 收起；保留当前视图，并显示等待任务或回答完成的友善提示。
- 提问卡片底部的上一题、下一题只显示箭头 icon，并提供 tooltip；答题阶段可用左右方向键切题，焦点位于自定义文本输入框时不拦截方向键。单选后立即显示下一道可见题，所有问题答完后在同一张卡片内展示可点击的问答复核列表；点击任一行回到对应问题修改。
- 提问卡的未提交回答在当前文件工作区内存中保存；收起编辑器、切换文件和切换面板组合后继续显示已有答案，刷新后再按服务端 pending interaction 恢复。
- 图片整理目标不明确时，卡片候选最多显示 3 篇笔记，以及“手填已有路径”“新建笔记”。选择后两项才显示 Markdown 路径输入框，避免一开始同时展示无关输入。
- 同一对话的近期文章不会自动触发“修改 / 新建”卡片。Agent 结合当前指令和最近对话判断写作目标；只有无法定位目标、范围或操作时才主动展示提问卡片。
- “图片或截图没有贴入文档”同样由 Agent 结合上下文定位目标；无法确定时以提问卡片收集必要信息。
- DiffDialog 的文字 diff 上方显示“图片变更”。新增卡片直接显示新图，不额外显示“新增”文字；移除卡片显示原图和移除标识，替换卡片并排显示原图、新图和方向提示。会话临时图片和已写入笔记图片都直接渲染，不以文件名代替预览。侧边栏的 Markdown 文件名和正文顶部完整路径均可打开文档；点击后关闭弹窗、展开编辑器并使用消息中的最新 operation set 打开文件。首次找不到目标会刷新文件树再判断，避免新建文件被误提示为不存在。

## 5. 文件与目录 Mention

```text
输入：请总结 @项目计划

┌─────────────────────────────────────────────┐
│ 项目计划                                     │
│ work/项目计划.md                             │
├─────────────────────────────────────────────┤
│ 2026 复盘                                    │
│ archive/2026 复盘.md                         │
└─────────────────────────────────────────────┘
```

- 输入 `@` 立即显示工作区文件和目录候选。
- 候选主行是文件名或目录名，次行是相对路径；每项名称和路径各显示一次。文件使用 `Icons.file`，目录统一使用文件树展开状态的 `Icons.folderOpen`。
- 以标题、文件名、目录名和路径做模糊包含匹配，最多显示 8 条。
- 选择文件或目录后，输入框在当前光标处显示约 24px 高的紧凑内联 mention 卡片。文件卡片使用文件树文件图标；目录卡片固定使用文件树展开状态的 `Icons.folderOpen`，名称使用 `--accent`，背景略深于输入框，圆角约 6px；宽度随名称适配，并与前后 prompt 保持同一文字流。
- 卡片不显示路径或内部 token。名称过长单行省略，悬停显示相对路径。光标紧邻卡片时，Backspace 或 Delete 一次移除整个卡片。
- 用户消息内按原始文字—mention 顺序使用相同的内联卡片。历史旧 token 在读取时转换为卡片，不在消息气泡中显示原始语法。
- 点击卡片打开只读预览。文件弹窗展示名称、相对路径和 Markdown 正文，隐藏 Notus 系统 frontmatter（`id / created_by / title`），正文区域支持滚动；目录弹窗提供目录内笔记列表，只有选中某篇笔记时才读取正文。桌面端弹窗宽度为视口约 65%，最大 960px；小屏幕使用接近全屏宽度。
- ArrowUp / ArrowDown 移动，Enter 选择，Esc 关闭；中文输入法组合态不拦截按键。
- 没有匹配项时显示“没有匹配的文件或目录”。

## 6. 个性化页

个性化页提供：

- 标题与文件名双向绑定。
- 开启后，在编辑器顶部修改文章标题并保存，文件名、文件树、`@` 文件候选和全局搜索结果同步显示新名称；目标文件名已存在时保留新标题并显示未同步文件名提示。
- 默认展开富文本编辑器。
- 默认展开 AI 聊天面板。
- 图片上传位置：左侧文字说明，右侧以本地、COS、OSS、R2 分段 tab 选择。未配置服务保持可点击，切换后显示含图床配置链接的提示。

## 设置弹窗内容规范

- 设置弹窗内部标题栏不显示当前功能名称、功能图标或“设置”，仅保留关闭按钮；窄屏额外显示打开菜单的 icon。所有设置内容区顶部也不重复显示所属功能名称，以侧栏或抽屉中的选中态标识当前功能。
- 模型、搜索、Skill、MCP、日志、个性化、图床、存储、快捷键、关于全部使用同一条居中的 860px 最大内容列；窄屏时内容列随可用宽度缩小。
- 700px 以下设置弹窗四周保留 12px 安全边距；原左侧导航改为左侧抽屉，标题栏以菜单 icon 打开，抽屉外遮罩和选择设置项都会关闭抽屉。内容区使用单列滚动，关闭按钮始终可见；抽屉遮罩不得关闭整个设置弹窗。
- 需要独立信息层级的设置页可使用标题组件；Skill 与 MCP 直接使用弹窗标题栏，内容区不重复显示功能名称。
- 个性化页使用与搜索配置相同的全宽设置区，内部以细分隔线区分各项设置，不使用多个紧凑小卡片。

## 7. 图床页

- 设置导航显示“图床”，承载腾讯云 COS、阿里云 OSS、Cloudflare R2 的独立参数配置。
- 图片上传位置只在个性化页选择；图床页不重复提供本地、COS、OSS、R2 的位置选择。
- 图床页使用搜索配置同款的服务商 Tab 切换阿里云 OSS、腾讯云 COS、Cloudflare R2；阿里云 OSS 固定为首项。首次进入时选中个性化页当前选择的云服务，本地存储时选中 OSS。当前 Tab 展示对应的 Bucket、Region/Endpoint、对象前缀、公开访问基础 URL、Access Key ID 和 Secret Access Key；不显示上传位置选择 tab。所有设置页自实现的分段 Tab 统一为 30px 按钮高度、34px 容器高度，按标签内容宽度收紧且默认限制在内容区宽度内；窄屏仅在 Tab 区自身横向滚动，不能带动设置页或弹窗横向溢出。个性化页的图片上传位置 Tab 在 720px 以下显示短名称“本地 / 腾讯 COS / 阿里 OSS / R2”，完整名称仅作为无障碍名称保留。
- 已保存密钥只显示“已保存”状态；输入框留空表示保持当前密钥。非当前使用的图床可显式清除密钥；当前使用的图床会提示先在个性化页切换上传位置。公开 URL 下方说明该地址会写入 Markdown，不能填写临时签名链接。

所有 tooltip 只显示单行且只描述操作；不显示快捷键组合。长度超过视口可用空间时在视口内省略，不换行也不越界。侧边栏文件区收起按钮的 tooltip 为“折叠”，展开按钮为“展开”。

## 9. 共享界面窄屏规则

- 通用弹窗宽度最大为 `100vw - 24px`，高度最大为 `100dvh - 24px`；底部操作区可换行，不把按钮挤出视口。

- 页面切换不使用全屏遮罩、居中 Logo 或顶部进度条式的全局加载特效；仅在发起请求、保存、恢复对话或 AI 生成的原操作区域显示局部状态反馈。
## 10. Skill 与 MCP 界面补充

- 设置导航使用线性立方体表示 `Skill`、双节点 Server 表示 `MCP`、键盘表示快捷键、机器人表示模型配置。未选中的 Skill 图标继承普通导航文字色；只有当前项选中时才使用强调色。Skill 与 MCP 页面使用右上操作栏和紧凑列表；Skill 资源行显示名称、描述和启停开关，当前 Git 安装记录可更新时在开关左侧显示紧凑“更新”按钮，不显示状态、来源或管理归属。新增弹窗点击遮罩不会关闭。Skill 操作栏依次提供重新扫描、导入 ZIP、从 Git 安装；窄宽度下允许换行。
- “导入 ZIP Skill”弹窗使用与 Markdown 导入一致的整块虚线拖放/点击上传区，不显示独立的选择按钮、未选择状态或安全说明。未选择时只显示上传动作与 `100 MiB` 上限，选中后在同一区域显示文件名与大小。文件选择、拖放和底部操作区均不得造成横向溢出。
- 用户在设置页启用、重新扫描或安装 Skill 后，当前 Agent 输入框的 `@` 候选应即时刷新，只显示启用且有效的 Skill。
- 用户也可以在 Agent 对话中直接请求安装 Git Skill 或添加 MCP。配置完整后 Agent 直接执行，不额外弹出确认卡片；最终消息和工具状态仅展示 Skill/Server 名称、传输方式和连接测试结果，不展示 Header 或环境变量值。新增成功后设置列表与 `@` Skill 候选即时同步。
- “调用 MCP”的 Server 新增/编辑弹窗提供 URL、本机 HTTP 开关和可增删的 Header 行。本机 HTTP 开关默认关闭，只允许直接本机访问时使用 `localhost`、`127.0.0.1` 或 `::1`；生产 Web 需要部署者设置 `NOTUS_ALLOW_LOOPBACK_HTTP_MCP=true`，且反向代理部署必须保持关闭。Header 值使用密码输入框，已保存的值可留空以保留，任何列表、任务时间线和日志都不回显其值。Header 行在窄宽度下换行，不能挤压或裁切操作按钮。
- MCP 设置页以内容宽度、左对齐的“调用 MCP”和“MCP 服务”两个分段标签分隔方向，默认打开“调用 MCP”。“MCP 服务”标签中，连接地址为单行可复制的 `/api/mcp` 地址，Token 列表显示名称、启用状态、自动应用或手动确认模式与授权工具数量。创建/编辑弹窗按基础只读、文件写入分组 Toggle；仅手动确认模式额外显示“手动确认 / 查询待确认变更状态”开关，切至自动应用时立即隐藏并移除该权限。创建和重新生成后的 Token 只在独立弹窗显示一次，明文输入框尾部使用带“复制 Token”提示的复制 icon，不再设置额外复制按钮。手动 Token 的待确认变更显示在同标签紧凑列表，点击“查看 Diff”复用现有 DiffDialog，提供应用和拒绝操作。Token、文件正文和外部凭据不在列表或日志界面回显。
- Agent 输入工具栏中，MCP 控件与联网搜索并列：关闭态显示双节点 Server 图标和“ MCP”，开启态仅高亮该按钮。点击关闭态会开启自动模式并弹出上方下拉，菜单只保留“自动”单选项；再次点击按钮关闭。控件和下拉不展示 Server 名、传输类型或说明文字。
- MCP 控件只有在当前运行环境可见且已启用的 Server 数量大于零时可点击。数量为零时按钮禁用、不高亮、不显示菜单，并将保存在浏览器中的自动偏好重置为关闭；悬停时 tooltip 显示“暂无 MCP 服务”。设置页停用或删除最后一个 Server 后，当前输入框立即回退。
- 设置导航包含“全局 Agent”。页面以定宽分段 Tab 和单一 Markdown 编辑表面管理 Agent 性格、写作风格和全局记忆；显示文件名、字符数、最后更新时间和历史入口，不显示用途说明。Electron 环境额外显示“打开所在位置”，不展示绝对路径。
- 输入工具栏允许换行；窄窗口下附件、图片、确认模式、联网与 MCP 控件保持可点击，不以横向裁切代替布局。
- `@` 候选的 Skill 使用 `Icons.skill`，主行是名称，次行是描述与来源；文件、目录和 Skill 保持同一行高、键盘选择和焦点样式。
- Agent 发起高风险资源操作时，复用工作区底部的提问卡片容器、层级和按钮样式，明确操作、目标、文件清单、校验结果与影响范围，并提供确认和取消；它使用资源确认语义，不额外创建聊天消息。

## Agent 失败与全局 Agent 编辑器

- 模型请求重试和终止错误统一显示在 Agent 工具链内。自动重试显示当前次数；任务已保留时默认展开脱敏错误，并显示“继续任务”或“配置完成后继续”。不在工具链下方重复渲染同一错误块。
- 任务受理后工具链立即显示“任务已提交 · 已等待 N 秒”，执行后切换为“正在处理 N 秒”；真实工具行按事件到达顺序以短距离淡入呈现。同批事件最多以 70ms 阶梯错开，避免多项工具突然堆叠；任务完成或失败后默认折叠，等待用户确认、回答或继续时保持展开。
- “继续任务”在旧 SSE 与 run lease 完成收尾后才可点击；首次点击立即进入本地 in-flight 状态，快速重复点击不得发起第二次恢复。仍有其他连接运行同一任务时显示“当前任务正在另一条连接中执行，请稍候查看进度”，不得展示 `SESSION_RUN_CONFLICT`。
- 全局 Agent 分段 Tab 容器最大 540px，单项基准宽度 156px，窄屏允许自身水平滚动。不显示页内功能说明和文件用途说明。编辑表面使用单一暖白卡片；次要操作在左，取消和主保存操作在右，未修改时禁用取消和保存。
