## 当前需求口径

- MCP 输入框仅在当前运行环境存在已启用 Server 时可开启；最后一个 Server 停用或删除后立即关闭并清除旧自动偏好，工具缓存不是入口可用性的前置条件。
- 全局 Agent 文件正文不入 SQLite。`soul.md` 每轮加载，`memory.md` 按章节相关性加载，`style.md` 只在写作任务加载；后续仍不引入其他全局文件或独立记忆向量库。

- 富文本编辑器工具栏支持弹窗自定义行列插入 Markdown 表格；侧边栏再次点击当前文档会取消选中并回到编辑器空态。
- 图床选择已从图床配置页移到个性化页；未配置服务仍可点击并提示前往对应配置。图床页使用搜索配置同款 Tab 维护 OSS、COS、R2 参数，首次展示当前云服务，本地时展示首项 OSS；个性化上传位置 Tab 在 720px 以下使用本地 / 腾讯 COS / 阿里 OSS / R2 缩写。
- 设置弹窗内部不重复显示“设置”；模型、搜索、日志、个性化、图床、存储、快捷键、关于统一使用 860px 内容列，顶部仅显示标题；个性化页与搜索配置使用同一全宽设置区。
- 全局 tooltip 改为视口内的单行省略显示；侧边栏文件区按钮提示为“折叠 / 展开”。
- 顶部搜索已收敛为 icon；编辑器/AI 面板宽度与 AI 输入区、消息面板尺寸已支持持久化和自适应。
- 工作区、设置和通用弹窗已完成响应式适配：不再固定为 1360×800；960px 以下文件树改为抽屉，760px 以下收起双栏中的编辑器、保留 AI 主工作区，Electron 最小窗口为 390×640。
- 编辑器与 AI 面板开关统一使用 32px 顶栏图标按钮，默认快捷键为 `Mod+B`、`Mod+U`；搜索 icon 提示为“搜索文件”。
- AI 面板已移除顶部品牌标识和空态图形，无消息时仅显示“你今天在想些什么？”。当前代码版本为 0.1.13，本轮未重新打包 `.lpk`。

- 文件工作区是唯一主入口；顶部没有文件、知识库、创作导航。
- 富文本编辑器和 AI 面板可独立展开或收起；同时展开时可拖动调整宽度。
- 关闭窗口后重新打开会恢复上次文档和编辑器、AI 面板开关组合；个性化默认值只用于已运行工作区从无文件状态打开文件。
- AI 面板不依赖当前文件。当前文件只服务编辑器、TOC 和保存。
- `@` 引用工作区文件、目录或启用且有效的 Skill。输入框和用户消息使用与 prompt 同一文字流的结构化 mention 节点，旧 token 会在读取时兼容转换；文件可从文件树拖入输入框并在落点生成同一节点。文件/目录卡片有明确 hover 与点击态，预览在 hover/focus 预取；弹窗底部左侧显示路径，标题以链接样式打开富文本编辑器。Skill 卡片仅显示描述 Tooltip，不打开文章预览。设置页的 Skill 启停、扫描和安装成功会即时刷新当前工作区候选。Agent 对文件按需调用 `read_file`，对目录先调用精确路径的 `analyze_folder`，不会默认扫描整个工作区。
- Agent 图片输入已接入 OpenAI Chat Completions 和 Anthropic Messages 协议。单条消息最多 30 张图片、10 个解析附件；单个对话最多 50 张图片、20 个解析附件，图片与附件按上传顺序混排。任务会完整提交媒体顺序数据，服务端合并、去重并复核图片分流；只发送图片时前端补入默认分析任务。`session_created` 回传已落库图片的受控预览地址，实时气泡始终优先使用该地址，不会在队列清理后继续使用临时对象 URL。待发送图片可复用笔记图片预览层并在当前队列内切换。
- 图片识别成功后，摘要以独立“图片识别结果”分类持久化，并和受控图片引用一起放进当前轮的首个 Agent 用户消息；历史轮次继续读取持久化摘要与受控引用，不重复发送原图，也不提供历史图片工具。识别失败不保存空摘要，当前轮保留原始视觉输入作为兜底；会话临时文件和预览仍限定在所属对话内。
- Agent 输入中的文本、Mention、图片和解析附件会长期保存在浏览器 IndexedDB，刷新后恢复；发送成功或清空后清理，浏览器端不设置过期时间。
- 新任务被服务端受理后，消息下方立即出现可展开的工具链和秒级计时；真正收到的工具事件按 SSE 到达顺序逐条展示并使用短入场动画，不以预设步骤伪造进度。任务完成后工具链通常折叠，但“查看图片”记录保留展开以展示按原图比例的可预览缩略图；等待确认、重试、失败时保持展开并提供相应操作。
- 会话图片保存在 `<sessionDir>/images` 并与消息元数据关联；当前不会因会话结束、删除、回滚或笔记应用自动销毁，上传失败的中间文件会清理。
- 用户要求把图片整理进笔记时，目标明确则直接生成预览；目标不唯一时通过提问卡片选择候选、手填已有路径或新建笔记。单选自动推进，全部回答在同一组件中复核。
- 图片新增、移除、替换已进入 operation set 和 DiffDialog。应用预览时复用图床设置写入本地、COS、OSS 或 R2；回滚只恢复 Markdown 引用，不物理删除图片资源。
- Agent 可创建、修改、重命名和移动文件或目录；删除能力不开放；所有写入沿用预览、自动确认、手动确认和回滚边界。
- 复制全文输出 Markdown 源文本，不生成图片 Base64。
- 新图片可按图床设置保存本地或上传 COS、OSS、R2；云端上传失败不插入图片，也不自动回退本地。
- 文件编辑器已拆分标题输入区与正文富文本区；Agent 系统 Frontmatter 不再显示给用户。
- 导入文件标题默认采用文件名；图片预览覆盖顶栏；设置页不再显示重复设置入口。
